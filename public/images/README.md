# Wilkerson Consulting: website images

AI-generated illustrative photographs for the Wilkerson Consulting website. They are still lifes. They are not photos of Ray Wilkerson, staff, clients, or the firm's actual office, and the site never presents them that way. No portrait of Ray was generated.

Generated with the Higgsfield connector, model **GPT Image 2.6** (quality: high, resolution: 2K, aspect ratio 16:9), on November 17, 2026. This set replaced an earlier set that looked too obviously AI-made (glossy desks, colorful charts on screens, a snowy mountain range, a hotel bell, hands with a loupe). Each prompt asked for a documentary, editorial look in a Reno or northern Nevada high-desert setting, with no people or hands, no snow, no charts or dashboards, and no readable text, numbers or logos. Each result was checked at full size for readable text before use. The hero was generated twice, because the first version had palm trees in the city view.

Web files: each `<name>.jpg` is 1920 x 1086 and under 400 KB, with `<name>-1200.jpg` and `<name>-800.jpg` copies that the pages load through `srcset`. The 2688 x 1520 PNG originals are kept by the operator, not in this repo.
